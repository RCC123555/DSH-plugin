# 1688本机浏览器查价

报价查价时必须读取本文件。自主执行关键词搜索、图片识别、候选筛选、商品规格选择、单价及采购档位读取，直到获得有效价格或明确的访问障碍。这里的自主执行依赖当前宿主提供的浏览器/电脑工具，不是后台爬虫；不能声称仅安装技能就新增了1688 API。

## 浏览器优先与故障分层

1. 优先使用用户已连接、已登录的本机浏览器。读取当前环境浏览器工具的完整文档，再用工具提供的浏览器及标签页清单绑定；浏览器ID、窗口ID、标签ID、控件编号只用当前返回值，不把旧编号写进插件。没有用户指定浏览器时优先已有1688会话，其次本机Chrome/Edge，不优先使用独立的未登录云端浏览器。
2. 首次先读取已打开的1688页。无可用页时新建一个本机浏览器标签，打开 `https://www.1688.com/`，检查真实显示的搜索框、登录状态、商品区域。不要读取Cookie、会话令牌、网络内部接口或浏览器配置文件。不得导出用户会话或把登录状态写进插件。
3. **通用网页检索工具的Internal Error、non-retryable、无法打开，只能记为web_tool_error。**立即转本机浏览器核查，不得据此写“1688打不开”“需要登录”“平台无此物料”，更不能直接给该批全部缺价。
4. **Debugger unattached、Tab not found、连接超时属于browser_connection_error。**刷新清单、重新绑定实际标签，按工具文档做一次恢复；旧标签失败可新建一个标签打开首页。如果首页已成功显示，不再当作全站故障。同一动作没有结果时先观察，不重复盲点。浏览器DOM读取失败但页面可见时，若宿主允许，按已提供的电脑技能改用原生窗口AX/截图；不能另开未授权调试端口、重启用户浏览器或使用自写CDP/Playwright连接绕开工具。
5. 若工具因无法可靠确定当前URL、用户中止或安全策略停止电脑操作，立即停止相应UI操作。记录browser_url_unverified或browser_connection_error，不能把它描述成1688拒绝访问；其余不依赖UI的核算、诊断仍可完成。
6. 只有真实页面显示扫码/密码登录、登录后看价，才记录login_required；复用现有登录不需要重复询问。需要新登录时让用户完成，不代填凭据。真实页面出现验证码才记录verification_required，交给用户完成，不绕过或自动处理。授权和工具限制以当前宿主为准。

## 关键词查询

1. 用 `scripts/1688-lookup.mjs plan input.json` 整理缺价任务。同规格同采购条件可共用一次查价证据；不同规格/单位/数量不可套用。计划文件不是搜索记录。
2. 从实物或图片提取“物料名＋关键规格＋材质＋安装形式”：如“2寸 PU 丝杆 刹车 万向轮 M10”“250mm 三节钢珠 滑轨 一副”。不要把整段用途、未确认尺寸或营销名全部塞入搜索词。
3. 在1688页面可见搜索框输入，点击页面搜索控件或回车。优先站内表单，避免手拼旧式GBK/UTF-8混合中文搜索URL。若页面跳转新标签，从新清单绑定结果页；不能误读原首页推荐商品为搜索结果。
4. 若无匹配，按证据调整一次关键词，例如保留尺寸安装型式、去掉营销词。看起来相似但尺寸/材质/刹车/接口不同的商品只能作候选。必要时改用图片查询，不无止境重试。
5. 打开最相关候选的真实商品详情链接，读取供应商、标题、参数、规格选项。用当前DOM/AX/截图中的控件选择目标规格；不得仅抄搜索卡片最低价。操作后刷新页面状态，核对所选SKU与价格的对应关系。

## 截图和以图搜款

- 用户要求根据产品图片/配件截图上1688查价，包含将相关商品图片用于1688以图搜款的任务授权。只使用必要的产品图或配件局部图；不上传整本报价表、价格底稿、账号画面、聊天内容及无关私人信息。截图含这些信息时先裁掉；若无法分离，再请求用户确认具体上传内容。仅给出图片但没有上1688查价意图，不据此上传。
- 先识别配件；只有整件图时优先取需查部件的清晰局部。可用宿主允许的本地图片裁切工具，保留原图，不用图像生成补造不存在的结构。
- 打开页面实际显示的“以图搜款/相机”入口，按浏览器当前文件上传文档设置图片文件，核对上传预览和图片结果。工具未提供上传能力时，记录image_upload_unavailable，仍用图片识别出的关键词查询，不能声称已经图片搜索。
- 图片结果需按关键尺寸、接口、材质和安装形式继续筛选，并进入详情选择规格看价。外观相似不等于同款，未知参数保持估算/待核。

## 单价、单位及采购档位

必须从已显示的商品详情记录：具体URL、供应商、标题、实际查询日期、已选规格、页面原价、币种、原单位、单位换算及可见MOQ/档位。优先普通批发价；首单优惠、样品价、券后价、最低起价、不同SKU混合区间价不能代替目标规格批量价。

- 采购需求＝每件用量×产品数量。包材先把长宽厚转换成m³/m²/m；包、盒、套、副先核实每报价单位包含的数量。500件产品每件4轮就是2000个轮，不是500个。
- 页面未公布MOQ或档位，按原规则写“未公布”；这本身不阻止采用已确认规格/单位的普通价格，不需强行证明不存在优惠档位。已公布则核对当前需求是否满足。
- “元/个”和“元/副”不可混用；1副含2条滑轨，若BOM按副计，targetUnitsPerQuoteUnit=1；BOM按单条计才=2。不能除以2之后仍写元/副。
- 保存 `priceEvidence`，使用 `1688-lookup.mjs validate evidence.json <目标单位采购量>` 校验并生成可直接合并到BOM的字段。证据至少包含已选规格、正常价格、单位换算、需求量以及可见文字或截图描述，不能把脚本校验通过当作真实访问证明。
- 用生成的notes承载底稿可见记录；本地截图如需保存放本轮work目录，报价交付后按原规则清理。不将账号截图或登录信息随插件发布。

## 失败后继续与记录

Chrome/Edge上传若提示需允许文件网址访问，记为image_upload_permission_required，这是浏览器扩展的本地文件权限限制，不是1688拒绝访问。按当前工具上传故障文档向用户提供扩展设置入口，不自行扩大权限，不把上传失败写成图片搜索成功。保留关键词检索能力并继续无关工作，等待用户配置后再端到端验证图片结果及详情价格。

每一类物料仅记录实际执行的步骤，日期取当前会话Asia/Shanghai日期，不能把计划关键词写成“已搜”。失败至少记channel、status、实际keywords/inputImage、浏览器实际URL（如果可验证）、工具/页面原始提示和已做的恢复。全站连接故障可共用一条会话诊断，其余未查询物料写“未执行，复用该会话故障”，不能虚构逐项1688搜索。

仍无有效价格时留空并保留BOM，可继续其他来源或其他产品。报告必须区分“已读详情规格价”“只有搜索候选价”“工具连接失败”“需用户登录/验证”。不得将工具错误统称为1688风控。不得发供应商消息、下单或改账户设置。



## 同规格多结果取平均（2.4.0）

默认对首批3—5个相关候选逐个核查，所有满足目标规格及采购条件的有效报价参与算术平均；不足2个时保留单一样本并标明，不为凑均价混入近似款。出现明显规格冲突时剔除并记原因。用户明确要求更大样本范围时按其范围执行。不得只选最低价或任意排除高价。

实际SKU参数优先于标题：实测标题称聚氨酯的商品，SKU可能为PP/PVC；材质、尺寸、颜色、刹车方式、丝杆直径长度、载荷等关键规格须一致，未知关键参数不能直接视为相同。搜索卡片新人价不能替代详情普通批发价。

建立batch.json：顶层comparisonKey（完整目标规格）、targetUnit、priceBasis（税费/运费口径）和samples数组。每个样本均为前述完整priceEvidence，并附同样的comparisonKey和priceBasis。不同规格或口径的样本保留自身真实值，脚本会排除；不改写其参数来凑同款。未知税费统一标明未注明，不伪称不含税。不同明确税运口径先可靠换算，否则分组不混算。

运行 `node scripts/1688-lookup.mjs average batch.json <目标单位需求量>`，得到可合并到BOM的均价字段。脚本先按报价单位归一，再去重（商品ID+SKU，不受跟踪参数影响），计算未提前舍入的算术平均；底稿保留每家链接、规格、原价、单位、日期、MOQ/档位、样本数、范围和排除原因。priceEvidence包含完整样本，核算器会复算，拒绝被篡改的均价或数量变化后失效的样本。

## 本机浏览器已验证的操作要点

本机Chrome的受支持DOM接口可完成站内搜索与SKU价格读取。工具提供DOM接口时优先使用，勿将原生AX包装器的Debugger错误当作网页不可访问。搜索可能新开标签：从浏览器用户标签清单查找并绑定新结果页，仅列代理已绑定标签可能看不到弹出的结果。

商品卡片可能命中“找相似”覆盖层而跳到图片相似页。点击后检查实际URL；若未进入商品详情，使用刚才结果页已经显示的真实商品href导航，再读SKU表，不猜商品ID。价格证据URL记录最终打开的HTTPS详情链接。连接失效时重新读取当前浏览器清单，不沿用旧浏览器ID。


## 图片面板提交与结果验收

实测Chrome允许访问文件网址后，可通过宿主文件选择器上传本任务的产品图片。上传成功仅说明面板显示“已上传1张图”，还必须提交图片搜索并取得结果。

首页文字搜索和图片面板可能有同名“搜索”按钮。不能用未限定的同名按钮或依赖匹配顺序，必须先观察图片面板所在容器，再限定到该容器内的提交控件。操作后核对新标签实际网址和已显示图片，确认是以图搜款结果；若实际进入的是首页推荐词的文字检索，记录为提交误入文字搜索，不能算图片查价成功。重新观察并定位正确控件后再提交。

2.4.1导出会逐条展示均价样本、原价、原报价单位、换算数量、换算单价、日期、MOQ/档位、独立可点击链接及观察记录。均价用Excel公式引用样本行；订单量低于任何已纳入样本的MOQ或超出档位时返回待核标记，须重新查价，不静默只平均剩余样本。价格、单位或条件被手工修改后应重新核实其对应SKU和证据。
