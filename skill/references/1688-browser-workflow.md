# 1688 查价流程

报价查价前必须读取本文件。插件自带持久 Chrome 与零依赖 CDP 客户端，查价直接用 `hwq_1688_*` 工具，不依赖宿主浏览器工具、ego 工具或用户手动开浏览器。工具只执行真实页面操作；计划、参数校验、搜索结果页都不能当作已访问详情的证明。

## 登录与浏览器生命周期

1. `hwq_1688_login action:"status"`：返回是否已登录及证据。已登录直接查价，不重复要求登录。
2. 未登录：`hwq_1688_login action:"open"` 打开登录页，请用户在插件浏览器窗口内扫码/登录；**绝不代填账号密码、不读取或导出 Cookie**。完成后用 `status` 确认。
3. `hwq_1688_login action:"flush"` 把登录态强制写入持久 profile（会优雅关闭并按同一 profile 重启插件 Chrome，登录态保留），重启后长期有效。
4. 插件使用独立 profile，不关闭用户其它浏览器；不要重启、另开调试端口或用自写脚本绕开工具。
5. **规格匹配是硬门槛**：`hwq_1688_search`/`hwq_1688_offer` 只有在螺纹规格（M6）、长度（×15）、头型三者与目标一致时才标 `specMatched:true`；“套装/配螺母/大全”等组合件价格不得当单颗价使用。搜到 3–5 个候选也可能一个都不匹配——这时如实报 pending，不要拿不符规格的价格凑数。
6. 出现滑块/图形验证码时，工具返回 `blocked:"captcha"` 及截图路径，提示用户在该窗口手动完成；不自动处理、不绕过。

## 故障分层

- 工具连不上、端口失效、CDP 超时：记为 `browser_connection_error`，工具会尝试重启浏览器或重试一次；仍失败就记录障碍并继续其他物料。
- 真实页面要求扫码/密码登录：`login_required`；页面出现验证码：`verification_required`，交由用户。
- 页面显示没有相关商品：`no_match`。
- 无法确认当前页面 URL，或工具因安全/超时中止操作：记 `browser_url_unverified`，不描述成“1688 拒绝访问”。
- **不得**把工具故障写成“1688 打不开”“需要登录”“平台无此物料”，也不得据此给整批物料缺价。只有真实页面确认的登录/验证问题才归因于站点。

## 实测要点

- 1688 搜索结果可能被“找相似”覆盖层或推荐页替换，必须以工具返回的真实详情 `url` 判定是否进入商品页，不能凭截图或页面标题推断。
- 图片面板与文字搜索可能使用同名按钮，选哪种搜索以工具返回的 `method` 和结果 URL 为准；工具走了关键词就不能声称已以图搜款。
- 只有图片上传成功不算图片搜索成功：须看到图片结果并进入详情选规格，或如实记录 `image_upload_unavailable`。

## 关键词查询

1. 从实物或图片提取“物料名＋关键规格＋材质＋安装形式”，如“2 寸 PU 丝杆 刹车 万向轮 M10”“250mm 三节钢珠 滑轨 一副”。不要把整段用途、未确认尺寸或营销名全部塞入搜索词。
2. 用 `hwq_1688_search` 传 `keywords` 搜索（与 `imagePath` 二选一）。结果页以工具返回的 `method/keyword/candidates` 为准，不把首页推荐商品误读为搜索结果。中文关键词由插件自己按 **GBK** 编码成 `keywords` 参数——1688 的 `s.1688.com/selloffer/offer_search.htm` 是 legacy 端点，按 GBK 解码该参数，若传 UTF-8 百分号编码，页面标题与搜索框会显示成「鍐呭叚瑙掓硶鍏伴潰铻轰笣」这类乱码（已真机对比确认）。所以看到中文乱码先怀疑编码层，不要照抄乱码去搜；工具返回的 `pageTitle` 是正确中文才说明这一层没问题。
3. 无匹配时按证据调整一次关键词，例如保留尺寸/安装型式、去掉营销词；看起来相似但尺寸、材质、刹车、接口不同的只能作候选。必要时改用图片查询，不无止境重试。
4. 打开最相关候选的详情，读取供应商、标题、参数与规格选项；不得仅抄搜索卡片最低价。核对所选 SKU 与价格对应关系后再取价。

## 图片与以图搜款

- 用户要求根据产品图/配件截图查价，包含将相关商品图用于 1688 以图搜款的授权。只上传必要的产品图或配件局部图；不上传整本报价表、价格底稿、账号画面、聊天内容及无关私人信息。截图含这些信息时先裁掉；无法分离时再请求用户确认。
- 仅给图片但没有上 1688 查价意图时，不据此上传。先识别配件；只有整件图时优先取需查部件的清晰局部。可用本地裁切工具保留原图，不用图像生成补造不存在的结构。
- 用 `hwq_1688_search` 传 `imagePath` 或以图搜款入口上传。上传预览和图片结果都要核对；**只有上传成功不算图片搜索成功**。工具未提供上传能力时记录 `image_upload_unavailable`，仍用图片识别出的关键词查询，不声称已图片搜索。
- 图片结果按关键尺寸、接口、材质、安装形式继续筛选并进入详情选规格看价。外观相似不等于同款，未知参数保持估算/待核。

## 单价、单位与采购档位

必须从已显示的详情记录：具体 URL、供应商、标题、实际查询日期、已选规格、页面原价、币种、原单位、单位换算及可见 MOQ/档位。优先普通批发价；首单优惠、样品价、券后价、最低起价、不同 SKU 混合区间价不能代替目标规格批量价。

- 采购需求＝每件用量×产品数量。包材先把长宽厚转换成 m³/m²/m；包、盒、套、副先核实每报价单位包含的数量。500 件产品每件 4 个轮就是 2000 个轮，不是 500 个。
- 页面未公布 MOQ 或档位，写“未公布”即可；这不阻止采用已确认规格/单位的普通价格，不需强行证明不存在优惠档位。已公布则核对当前需求是否满足。
- “元/个”和“元/副”不可混用；1 副含 2 条滑轨，BOM 按副计时系数 1，按单条计时系数 2，不能除以 2 后仍写元/副。
- 实际 SKU 参数优先于标题：标题称聚氨酯的商品 SKU 可能是 PP/PVC；材质、尺寸、颜色、刹车方式、丝杆直径长度、载荷等关键规格须一致，未知关键参数不能直接视为相同。

## 证据记录

每条 1688 价格保存完整 `priceEvidence`（13 项，字段见[输入及执行接口](input-and-runtime.md)）：详情 URL、供应商、标题、查询日期、搜索方式与关键词/图片、证据形式、可见文字、已选规格及匹配结论、原始单价/币种/价格类型、单位换算、MOQ、档位。工具返回的真实 `capturedAt` 与 URL 直接使用，不手工改写；不伪造链接、价格或页面文字。截图如需保存放本轮 `workDir`，交付后清理，不随插件发布账号信息。

## 同规格多结果取平均

1. 默认对首批 3–5 个相关候选逐个核查，所有满足目标规格及采购条件的有效报价参与算术平均；不足 2 个时保留单一样本并标明，不为凑均价混入近似款。
2. 用 `hwq_1688_average` 传入样本、`comparisonKey`（完整目标规格）、`targetUnit`、`priceBasis`（税费/运费口径）与目标单位需求量。样本须带同样的对比键与口径；不同规格或口径的样本保留真实值，由工具排除，不改写参数凑同款。
3. 工具先按报价单位归一，再按商品 ID＋SKU 去重（不受跟踪参数影响），计算未提前舍入的算术平均；底稿保留每家链接、规格、原价、单位、日期、MOQ/档位、样本数、范围和排除原因。
4. 不得只选最低价或任意排除高价。未知税费统一标“未注明”，不伪称不含税；不同明确税运口径先可靠换算，否则分组不混算。
5. 采购数量使任一已纳入样本的 MOQ/档位失效时，均价记录失效，须重新查价，不静默只平均剩余样本。

## 失败后继续与记录

每一类物料只记录实际执行的步骤，日期取当前会话 Asia/Shanghai 日期，不能把计划关键词写成“已搜”。失败至少记录 channel、status、实际 `keywords`/`inputImage`、浏览器实际 URL（如果可验证）、工具/页面原始提示和已做的恢复；工具的分类只作诊断，不能据报错推测站点登录状态。任务未执行写 `not_started`；全站连接故障可共用一条会话诊断，其余未查询物料写“未执行，复用该会话故障”，不虚构逐项搜索。

仍无有效价格时留空并保留 BOM，可继续其他来源或其他产品。报告必须区分“已读详情规格价”“只有搜索候选价”“工具连接失败”“需用户登录/验证”，不得把工具错误统称为 1688 风控。**禁止**：发询价、下单、发消息、改账户设置、导出 Cookie 或凭据、绕过验证码。
